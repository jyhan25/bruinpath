OVERVIEW
--------
Built the full project skeleton for BruinPath, a UCLA degree planning assistant.
The app lets students upload their transcript and Degree Audit Report (DAR) to
receive a personalized quarter-by-quarter graduation plan.

BACKEND ROUTES IMPLEMENTED
---------------------------
GET  /health
  - Returns {"status": "ok"}
  - Used for uptime checks and Docker healthchecks

GET  /majors
  - Returns list of Major objects (id, name, department, total_units, description)
  - Currently returns 4 stub majors (CS, Math, Econ, Stats)
  - Intended to be backed by a DB table once schema is set up

POST /parse-transcript  (multipart/form-data, field: file)
  - Accepts a UCLA transcript PDF (up to 20 MB)
  - Extracts text using PyMuPDF (preferred) or pdfplumber as fallback
  - Applies regex heuristics to pull: student name, major, cumulative GPA,
    and a list of courses (course_id, title, units, grade, term)
  - Returns ParseTranscriptResponse
  - Note: regex patterns are heuristic and will need tuning against real samples

POST /parse-dar  (multipart/form-data, field: file)
  - Accepts a UCLA Degree Audit Report PDF
  - Extracts text and applies regex to identify requirement blocks
  - Each block yields: category, requirement name, status (complete/in_progress/
    incomplete), units_required, units_applied
  - Returns ParseDARResponse

POST /audit  (JSON body: AuditRequest)
  - Takes a parsed transcript + parsed DAR
  - Rule engine checks each DAR requirement against the set of completed courses
    (courses with a passing grade: not F, NP, W, or I)
  - Splits results into passed / pending / failed lists
  - Computes overall completion_percentage
  - Returns AuditResponse

POST /generate-plan  (JSON body: PlanRequest)
  - Takes a parsed transcript + parsed DAR + optional target graduation term
    and max units per quarter (default 20)
  - Identifies all unmet requirements and their missing courses
  - Determines the next quarter after the student's last recorded term
  - Greedily packs courses into quarters respecting the unit cap
  - Returns list of QuarterPlan objects and an estimated graduation term
